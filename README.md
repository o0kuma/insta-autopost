# 인스타 자동 게시 (insta-autopost)

사진과 짧은 메모를 올리면 AI(Claude)가 캡션과 해시태그를 쓰고, 사장님이 확인하고 승인하면 정해진 시간에 인스타그램에 자동으로 올려 주는 도구예요. 올린 게시물에 달린 댓글도 한곳에서 보고, AI가 제안한 답글을 달 수 있어요.

```
사진 + 메모 업로드
   → AI가 사진을 보고 캡션·해시태그 작성 (사진은 인스타 규격 JPEG·비율로 자동 보정)
   → 대시보드에서 확인·수정 ("더 짧게" 같은 수정 요청도 가능)
   → 승인하면 예약 시간에 자동 게시 (사람이 승인하지 않은 글은 올라가지 않음)
   → 게시물 반응(좋아요·도달·저장) 확인, 댓글에 AI 답글 제안
```

---

## 1. 빠르게 써 보기 (테스트 모드)

키나 토큰을 하나도 넣지 않아도 **테스트 모드**로 화면과 흐름을 전부 확인할 수 있어요. 테스트 모드에서는 인스타에 실제로 올라가지 않아요.

**준비물:** Windows PC, [Python 3.10 이상](https://www.python.org/downloads/) (설치할 때 "Add python.exe to PATH" 체크)

1. 이 폴더를 **짧은 경로**에 두세요. 예: `C:\insta-autopost`
   (경로가 너무 길면 Windows에서 사진 처리 라이브러리가 열리지 않아요.)
2. `start.bat`을 더블클릭하세요.
   처음 한 번은 필요한 패키지를 설치하느라 1~2분 걸려요. 브라우저에 대시보드(`http://127.0.0.1:5000`)가 열려요.
3. 끄려면 검은 창에서 `Ctrl+C`를 누르거나 창을 닫으세요.

터미널에서 직접 실행하려면:

```powershell
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
copy .env.example .env
.venv\Scripts\python run.py
```

Claude 키가 없으면 AI 초안 대신 메모가 본문에 그대로 들어가요. 나머지 흐름(예약, 가짜 게시, 댓글 화면)은 그대로 써 볼 수 있어요.

## 2. 실제로 연결하기

`.env` 파일을 메모장으로 열어서 아래 값을 채우고, 앱을 다시 실행하세요. 설정 페이지와 `python run.py check`에서 연결 상태를 확인할 수 있어요.

### ① Claude API 키 (캡션·답글 작성)

1. [console.anthropic.com](https://console.anthropic.com)에 가입하고 결제 수단을 등록하세요.
2. API Keys 메뉴에서 키를 만들어 `.env`의 `ANTHROPIC_API_KEY=`에 붙여 넣으세요.

비용은 쓴 만큼 나가요. 초안 1개에 대략 몇십~백몇십 원 수준이에요(사진 장수와 글 길이에 따라 달라지는 대략적인 값). 콘솔에서 월 사용 한도를 걸어 두면 안심이에요.

### ② 인스타그램 토큰

인스타 공식 API는 **프로페셔널 계정(비즈니스 또는 크리에이터)** 만 쓸 수 있어요.

1. **계정 전환:** 인스타 앱 → 설정 → 계정 유형 및 도구 → 프로페셔널 계정으로 전환
2. **Meta 앱 만들기:** [developers.facebook.com](https://developers.facebook.com) → 내 앱 → 앱 만들기 → 사용 사례에서 "Instagram에서 메시지 및 콘텐츠 관리"를 고르세요.
3. **토큰 발급:** 앱 대시보드 → Instagram API → "Instagram 로그인을 통한 API 설정" → 액세스 토큰 생성에서 인스타 계정을 추가하고 로그인·권한 허용을 하면 토큰이 나와요.
   - 계정 추가가 안 되면: 앱 역할 → Instagram 테스터로 계정을 추가하고, 인스타 웹의 설정 → 앱 및 웹사이트 → 테스터 초대에서 수락하세요.
   - 필요한 권한: `instagram_business_basic`, `instagram_business_content_publish`, `instagram_business_manage_comments`, `instagram_business_manage_insights`
4. 발급된 토큰을 `.env`의 `IG_ACCESS_TOKEN=`에 붙여 넣으세요.

본인 계정에만 쓴다면 Meta의 앱 검수 없이 개발 모드로 쓸 수 있어요. 메뉴 이름은 Meta가 자주 바꾸니, 화면이 다르면 [공식 문서](https://developers.facebook.com/documentation/instagram-platform/content-publishing)를 참고하세요.

토큰은 60일짜리이고, 앱이 켜져 있으면 1주일마다 알아서 갱신해요. 앱을 두 달 가까이 꺼 뒀다면 토큰을 새로 발급해서 `.env`에 다시 넣으세요.

### ③ Cloudinary (사진 공개 URL)

인스타 API는 사진 파일을 직접 받지 않고 **인터넷에 공개된 사진 주소**만 받아요. 그래서 게시 직전에 사진을 Cloudinary에 올려서 주소를 만들어요.

1. [cloudinary.com](https://cloudinary.com)에 가입하세요 (무료 플랜으로 충분해요).
2. Dashboard의 Cloud name, API Key, API Secret을 `.env`의 `CLOUDINARY_...` 칸에 넣으세요.

Cloudinary에 올라간 사진은 주소를 아는 사람이면 볼 수 있어요. 어차피 인스타에 공개로 올릴 사진만 올라가요.

## 3. 쓰는 방법

| 화면 | 하는 일 |
|---|---|
| **+ 새 게시물** | 사진(최대 10장, 여러 장이면 슬라이드)과 메모를 올리면 AI 초안이 만들어져요. 메뉴 이름·가격·이벤트처럼 사진만으로 모르는 사실은 메모에 적어 주세요. AI는 적힌 사실만 써요. |
| **게시물 → 검토 대기** | 초안을 열어 본문과 해시태그를 고치거나 "AI 다시 쓰기"로 수정을 요청해요. 왼쪽에 인스타에서 보일 모습이 미리 보여요. |
| **확인 완료 · 예약하기** | 설정한 기본 게시 시간 중 비어 있는 가장 가까운 시간으로 예약돼요. 시간은 직접 바꿀 수도 있어요. |
| **게시됨** | 좋아요, 댓글, 도달, 저장, 공유 수를 보여 줘요. |
| **실패** | 왜 실패했는지 보여 줘요. 고친 뒤 다시 예약하거나 바로 게시할 수 있어요. |
| **댓글** | 최근 게시물 10개의 댓글 중 답글이 없는 것부터 보여 줘요. "AI 답글 제안"으로 초안을 받고, 고쳐서 답글을 달아요. |
| **설정** | 가게 이름, 말투, 항상 넣을 해시태그, 기본 게시 시간 등을 정해요. AI가 글을 쓸 때 이 정보를 참고해요. |

## 4. 알아 둘 점

- **예약 게시는 이 프로그램이 켜져 있을 때만 돼요.** PC가 꺼져 있던 동안 지나간 예약은 다음에 켤 때 바로 올라가요. 항상 켜 두기 어렵다면 클라우드 서버에 올리는 방법이 있어요(다음 단계 참고).
- 인스타 API로 올릴 수 있는 게시물은 24시간에 50~100개 정도로 제한돼 있어요(설정 페이지에 현재 사용량이 보여요). 가게 운영에는 충분해요.
- 사진은 JPEG로 바꾸고, 인스타가 허용하는 비율(세로 4:5 ~ 가로 1.91:1)에 맞춰 가운데 기준으로 잘라요. 설정에서 "흰 여백 넣기"로 바꿀 수 있어요. 여러 장이면 첫 장의 비율에 맞춰요.
- 대시보드에서 게시물을 삭제하면 대시보드 기록만 지워져요. 인스타에 올라간 글은 인스타 앱에서 지우세요.
- `.env`에는 비밀 키가 들어 있으니 다른 사람에게 보내거나 인터넷에 올리지 마세요.

## 5. 파일 구조

```
insta-autopost/
├─ start.bat            더블클릭 실행
├─ run.py               대시보드 + 예약 스케줄러 실행 (run.py check: 연결 점검)
├─ .env.example         키·토큰 설정 양식 (.env로 복사해서 사용)
├─ brand.json           가게 정보 (설정 페이지에서 수정)
├─ requirements.txt
├─ autopost/
│  ├─ ai.py             Claude로 캡션·해시태그·답글 작성
│  ├─ instagram.py      인스타 API (게시, 댓글, 통계, 토큰 갱신) + 테스트 모드
│  ├─ images.py         사진 보정 (JPEG, 비율, 크기, HEIC 지원)
│  ├─ hosting.py        Cloudinary 업로드
│  ├─ publisher.py      예약 게시 스케줄러
│  ├─ db.py             게시물 대기열 (SQLite)
│  ├─ web.py            대시보드 (Flask)
│  ├─ templates/, static/
└─ data/                실행하면 생김: 사진, 데이터베이스
```
