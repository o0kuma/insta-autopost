# 인스타 자동 게시 (insta-autopost)

사진과 짧은 메모를 올리면 AI(Claude)가 캡션과 해시태그를 쓰고, 사장님이 확인하고 승인하면 정해진 시간에 인스타그램에 자동으로 올려 주는 도구예요. 올린 게시물에 달린 댓글도 한곳에서 보고, AI가 제안한 답글을 달 수 있어요.

```
폰으로 사진 찍고 + 메모
   → AI가 사진을 보고 캡션·해시태그 작성 (사진은 인스타 규격 JPEG·비율로 자동 보정)
   → 확인·수정 ("더 짧게" 같은 수정 요청도 가능)
   → 승인하면 예약 시간에 자동 게시 (승인하지 않은 글은 절대 올라가지 않음)
   → 게시물 반응(좋아요·도달·저장) 확인, 댓글에 AI 답글 제안
```

클라우드에 한 번 올려 두면 사장님은 **폰에서 링크만 열어서** 쓸 수 있어요. 설치할 것도, 켜 둘 PC도 필요 없어요.

---

## 사장님이 쓰는 방법

1. 받은 링크를 폰에서 열고 비밀번호를 입력하세요. 한 번 로그인하면 30일 동안 유지돼요.
2. **홈 화면에 추가**해 두면 앱처럼 쓸 수 있어요.
   - 아이폰(Safari): 공유 버튼 → 홈 화면에 추가
   - 안드로이드(Chrome): 오른쪽 위 ⋮ → 홈 화면에 추가
3. **처음 한 번만:** 설정 → **인스타 연결하기** → 인스타 로그인 → 허용. 연결되면 설정 화면에 내 계정 이름이 보여요.
4. 이후에는 이렇게 써요.

| 화면 | 하는 일 |
|---|---|
| **+ 새 게시물** | 사진(최대 10장, 여러 장이면 슬라이드)과 메모를 올리면 AI 초안이 만들어져요. 메뉴 이름·가격·이벤트처럼 사진만으로 모르는 사실은 메모에 적어 주세요. AI는 적힌 사실만 써요. |
| **게시물 → 검토 대기** | 초안을 열어 본문과 해시태그를 고치거나 "AI 다시 쓰기"로 수정을 요청해요. 인스타에서 보일 모습이 미리 보여요. |
| **확인 완료 · 예약하기** | 기본 게시 시간 중 비어 있는 가장 가까운 시간으로 예약돼요. 시간은 직접 바꿀 수도 있어요. |
| **게시됨** | 좋아요, 댓글, 도달, 저장, 공유 수를 보여 줘요. |
| **실패** | 왜 실패했는지 보여 줘요. 고친 뒤 다시 예약하거나 바로 게시할 수 있어요. |
| **댓글** | 최근 게시물 10개의 댓글 중 답글이 없는 것부터 보여 줘요. "AI 답글 제안"으로 초안을 받고, 고쳐서 답글을 달아요. |
| **설정** | 가게 이름, 말투, 항상 넣을 해시태그, 기본 게시 시간 등을 정해요. AI가 글을 쓸 때 이 정보를 참고해요. |

## 설치하는 사람용: 클라우드(Render)에 배포하기

한 번만 하면 돼요. 저장소에 `render.yaml`과 `Dockerfile`이 들어 있어서 Render가 설정을 그대로 읽어요.

**비용:** Render의 무료 인스턴스는 15분 동안 접속이 없으면 잠들고 영구 디스크도 못 써서, 예약 게시를 하려면 가장 작은 **유료 인스턴스 + 1GB 디스크**가 필요해요(현재 가격은 [Render 요금 페이지](https://render.com/pricing)에서 확인). 여기에 Claude API 사용료가 쓴 만큼 나가요.

### 1. 사장님 인스타 계정 준비

인스타 앱 → 설정 → 계정 유형 및 도구 → **프로페셔널 계정(비즈니스 또는 크리에이터)** 으로 전환해 주세요. 인스타 공식 API는 프로페셔널 계정만 쓸 수 있어요.

### 2. Meta 앱 만들기

1. [developers.facebook.com](https://developers.facebook.com) → 내 앱 → 앱 만들기 → 사용 사례에서 "Instagram에서 메시지 및 콘텐츠 관리"를 고르세요.
2. 앱 대시보드 → Instagram → **Instagram 로그인을 통한 API 설정** → 비즈니스 로그인 설정에서 **Instagram 앱 ID**와 **Instagram 앱 시크릿**을 복사해 두세요. (Facebook 앱 ID가 아니에요.)
3. 앱이 개발 모드일 때는 앱에 추가된 계정만 연결할 수 있어요. 앱 역할 → **Instagram 테스터**로 사장님 계정을 추가하고, 사장님이 인스타 웹의 설정 → 앱 및 웹사이트 → 테스터 초대에서 수락하게 해 주세요.

메뉴 이름은 Meta가 자주 바꾸니, 화면이 다르면 [비즈니스 로그인 공식 문서](https://developers.facebook.com/docs/instagram-platform/instagram-api-with-instagram-login/business-login)를 참고하세요.

### 3. Render에 배포

1. [render.com](https://render.com)에 가입하고 GitHub 계정을 연결하세요.
2. **New → Blueprint** → 이 저장소를 고르세요.
3. 아래 값을 입력하라는 화면이 나와요.

| 이름 | 넣을 값 |
|---|---|
| `DASHBOARD_PASSWORD` | 사장님이 로그인할 비밀번호 (길고 추측하기 어렵게) |
| `ANTHROPIC_API_KEY` | [console.anthropic.com](https://console.anthropic.com)에서 만든 Claude API 키 |
| `IG_APP_ID` | 2단계의 Instagram 앱 ID |
| `IG_APP_SECRET` | 2단계의 Instagram 앱 시크릿 |

나머지(세션 암호화 키, 디스크 경로, 시간대, 공개 주소)는 자동으로 채워져요. 배포가 끝나면 `https://insta-autopost-xxxx.onrender.com` 같은 주소가 생겨요.

### 4. Meta 앱에 리디렉션 주소 등록

배포된 주소로 로그인한 뒤 **설정 → "설치한 사람용: Meta 앱에 등록할 리디렉션 주소"** 를 펼치면 `https://…/instagram/callback` 주소가 보여요. 이 주소를 Meta 앱의 비즈니스 로그인 설정 → **OAuth 리디렉션 URI**에 그대로 넣고 저장하세요. 한 글자라도 다르면 연결이 실패해요.

### 5. 사장님께 전달

링크와 비밀번호를 보내고, 위의 "사장님이 쓰는 방법" 3번(인스타 연결하기)만 같이 해 주면 끝이에요.

### 운영 메모

- 인스타 토큰은 60일짜리이고, 서버가 1주일마다 알아서 갱신해요.
- 사진, 데이터베이스, 설정 화면에서 고친 가게 정보는 Render 디스크(`/var/data`)에 저장돼서 재배포해도 남아요. Render가 디스크를 하루 한 번 스냅샷으로 보관해요.
- 인스타는 게시할 때 이 서버의 `/p/<무작위 파일명>.jpg` 주소에서 사진을 가져가요. 파일명은 추측할 수 없는 난수라 따로 Cloudinary가 필요 없어요.
- 디스크가 붙은 서비스는 배포할 때 몇 초 동안 접속이 끊겨요. 그 사이 예약 시간이 지나도 서버가 다시 켜지면 바로 올려요.
- 비밀번호를 바꾸려면 Render 대시보드의 Environment에서 `DASHBOARD_PASSWORD`를 고치면 돼요.
- 연결 상태는 설정 화면에서 볼 수 있어요. 서버 셸에서는 `python run.py check`로도 확인할 수 있어요.

## 이 PC에서 실행하기 (테스트용, 또는 클라우드 없이 쓰기)

키나 토큰이 하나도 없어도 **테스트 모드**로 화면과 흐름을 전부 확인할 수 있어요. 테스트 모드에서는 인스타에 실제로 올라가지 않아요.

1. [Python 3.10 이상](https://www.python.org/downloads/)을 설치하세요 (설치할 때 "Add python.exe to PATH" 체크).
2. 이 폴더를 `C:\insta-autopost`처럼 **짧은 경로**에 두세요. 경로가 너무 길면 Windows에서 사진 처리 라이브러리가 열리지 않아요.
3. `start.bat`을 더블클릭하세요. 처음 한 번은 패키지를 설치하느라 1~2분 걸리고, 브라우저에 `http://127.0.0.1:5000`이 열려요.

터미널에서 직접 실행하려면:

```powershell
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
copy .env.example .env
.venv\Scripts\python run.py
```

이 PC에서 실제로 게시하려면 `.env`에 아래를 채우고 다시 실행하세요.

- `ANTHROPIC_API_KEY`: Claude API 키
- `IG_ACCESS_TOKEN`: Meta 앱 대시보드의 "Instagram 로그인을 통한 API 설정 → 액세스 토큰 생성"에서 발급한 토큰. '인스타 연결하기' 버튼은 https 공개 주소가 있어야 동작해서, 이 PC에서는 토큰을 직접 넣어요.
- `CLOUDINARY_CLOUD_NAME` / `API_KEY` / `API_SECRET`: 인스타 API는 공개된 사진 주소만 받기 때문에, 공개 주소가 없는 PC에서는 [Cloudinary](https://cloudinary.com)(무료 플랜)에 사진을 올려서 주소를 만들어요.

이 PC에서 쓸 때는 프로그램이 켜져 있어야 예약 게시가 돼요. 꺼져 있던 동안 지나간 예약은 다음에 켤 때 바로 올라가요. 비밀번호(`DASHBOARD_PASSWORD`) 없이 쓰는 건 이 PC(127.0.0.1)에서만 허용되고, 외부에 공개하는 주소로 띄우면 비밀번호가 없을 때 실행을 멈춰요.

## 알아 둘 점

- 인스타 API로 올릴 수 있는 게시물은 24시간에 50~100개 정도로 제한돼 있어요(설정 화면에 현재 사용량이 보여요). 가게 운영에는 충분해요.
- 사진은 JPEG로 바꾸고, 인스타가 허용하는 비율(세로 4:5 ~ 가로 1.91:1)에 맞춰 가운데 기준으로 잘라요. 설정에서 "흰 여백 넣기"로 바꿀 수 있어요. 여러 장이면 첫 장의 비율에 맞춰요.
- 예약 시간은 `TIMEZONE`(기본 Asia/Seoul) 기준이에요. 서버가 다른 나라에 있어도 12:00 예약은 한국 시간 12시에 올라가요.
- 대시보드에서 게시물을 삭제하면 대시보드 기록만 지워져요. 인스타에 올라간 글은 인스타 앱에서 지우세요.
- API 키, 앱 시크릿, 비밀번호는 `.env`나 Render 환경 변수에만 넣고, 저장소에 올리거나 다른 사람에게 보내지 마세요.

## 파일 구조

```
insta-autopost/
├─ render.yaml          Render 배포 설정 (Blueprint)
├─ Dockerfile           클라우드 실행 환경
├─ start.bat            이 PC에서 더블클릭 실행
├─ run.py               대시보드 + 예약 스케줄러 실행 (run.py check: 연결 점검)
├─ .env.example         키·토큰 설정 양식
├─ brand.json           가게 정보 기본값 (설정 화면에서 고친 값은 data/에 저장)
├─ requirements.txt
└─ autopost/
   ├─ web.py            대시보드 (로그인, 게시물, 댓글, 설정, 인스타 연결)
   ├─ instagram.py      인스타 API (연결 버튼, 게시, 댓글, 통계, 토큰 갱신) + 테스트 모드
   ├─ ai.py             Claude로 캡션·해시태그·답글 작성
   ├─ images.py         사진 보정 (JPEG, 비율, 크기, HEIC 지원)
   ├─ hosting.py        사진 공개 주소 (이 서버 또는 Cloudinary)
   ├─ publisher.py      예약 게시 스케줄러
   ├─ db.py             게시물 대기열 (SQLite)
   ├─ config.py         환경 변수와 설정
   └─ templates/, static/
```
